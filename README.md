# Spotify Playlist Guardian

A lightweight, zero-dependency serverless tool that monitors your Spotify playlists on **GitHub Actions**, backs up tracklists to Git, and alerts you whenever songs disappear (due to accidental taps, swipe gestures, or catalog removals).

## Features

- **Read-Only by Design:** Requests only `playlist-read-private` and `playlist-read-collaborative` scopes — the tool can never modify or delete anything in your Spotify account.
- **Zero Dependencies:** Written entirely in Python 3 standard library (`urllib`, `json`, `http.server`) — no `pip install` steps or broken third-party packages.
- **2026 Spotify Web API Ready:** Supports the `/v1/playlists/{id}/items` endpoint and schema introduced in February 2026 (with automatic fallback for legacy responses) and loopback IP OAuth (`127.0.0.1`).
- **Git-Backed Version History:** Automatically maintains:
  - `data/snapshot.json` — structured playlist state
  - `PLAYLIST.md` — human-readable Markdown table of all current tracks
  - `REMOVED_HISTORY.md` — append-only log of every removed track with a direct Spotify link
- **Instant Alerts:**
  - **GitHub Issues (built-in):** Opens an issue automatically when a track disappears, triggering a free GitHub email notification.
  - **Telegram Bot (optional):** Sends an instant message with clickable links to re-add missing songs in one tap.

## Setup Guide

### 1. Create a Spotify Developer App

1. Open the [Spotify Developer Dashboard](https://developer.spotify.com/dashboard) and sign in.
2. Click **Create app**:
   - **App name:** `Playlist Guardian`
   - **App description:** `Personal playlist monitor and backup`
   - **Redirect URIs:** enter this exact loopback URL and click **Add**:
     ```text
     http://127.0.0.1:8888/callback
     ```
     *(Note: Spotify blocks `localhost` redirect URIs; an explicit loopback IP is required.)*
   - Check **Web API** and click **Save**.
3. Open your app's **Settings** and copy the **Client ID** and **Client Secret**.

### 2. Generate Your Refresh Token (One-Time Local Step)

Clone this repository (or run locally) and execute:

```bash
python get_refresh_token.py
```

1. Paste your `Client ID` and `Client Secret`.
2. Approve the read-only permissions prompt in your browser.
3. Copy the `SPOTIFY_REFRESH_TOKEN` printed in the terminal.

### 3. Configure GitHub Repository Secrets

In your GitHub repository, navigate to **Settings → Secrets and variables → Actions → New repository secret** and add:

| Secret Name | Required | Description |
|---|---|---|
| `SPOTIFY_CLIENT_ID` | Yes | Client ID from the Spotify Developer Dashboard |
| `SPOTIFY_CLIENT_SECRET` | Yes | Client Secret from the Spotify Developer Dashboard |
| `SPOTIFY_REFRESH_TOKEN` | Yes | Token generated by `get_refresh_token.py` |
| `SPOTIFY_PLAYLIST_ID` | Yes | Playlist URL (`https://open.spotify.com/playlist/...`), URI, or ID (comma-separated for multiple playlists) |
| `TELEGRAM_BOT_TOKEN` | Optional | Bot token from [@BotFather](https://t.me/BotFather) |
| `TELEGRAM_CHAT_ID` | Optional | Your numeric chat ID (e.g. via [@userinfobot](https://t.me/userinfobot)) |

### 4. Run Your First Sync

1. Open the **Actions** tab in your GitHub repository.
2. Select **Spotify Playlist Guardian** on the left and click **Run workflow**.
3. Once completed (~10 seconds), `PLAYLIST.md` and `data/snapshot.json` will be committed automatically. From then on, the workflow checks your playlist twice daily at `08:15` and `20:15` UTC.

## Running Locally

Copy `.env.example` to `.env`, fill in your credentials, and run:

```bash
python guardian.py
```
